# 👑 XAU/USD Gold Analysis Terminal & Trading Suite

An interactive, professional web application for analyzing **XAU/USD (Gold)** with real-time candlestick charts, technical indicators (EMA, Bollinger Bands, RSI, MACD, Fibonacci), trading calculators, AI confluence signal scanner, and macro news dashboard.

## ✨ Features

- **📊 High-Performance Financial Terminal:** HTML5 Canvas candlestick chart supporting timeframes (M15, H1, H4, D1), zoom/pan controls, and crosshairs.
- **📈 Technical Overlays:**
  - EMA 20, EMA 50, EMA 200
  - Bollinger Bands (20, 2.0)
  - Fibonacci Retracement ($0.0\%, 23.6\%, 38.2\%, 50.0\%, 61.8\%, 100.0\%$)
  - Auto Support & Resistance Zones
- **🎯 Sub-Chart Indicators:** RSI (14) with OB/OS boundaries and MACD Histogram & Signal lines.
- **🧮 Trading Tools & Calculators:**
  - **Lot Size & Risk Calculator:** Position sizing based on account balance, risk %, stop loss pips, and leverage.
  - **Pivot Points Calculator:** Standard, Fibonacci, and Camarilla algorithms.
  - **Intermarket Correlation Matrix:** Track gold against DXY, US10Y Yields, Brent Oil, and EUR/USD.
- **🤖 Automated Confluence Signal Scanner:** Multi-timeframe trend detector with Buy/Sell setups, SL, TP1/2/3, R:R ratios, and technical rationale.
- **🛡️ Trade Strategy Simulator:** Paper trading simulator with open positions tracking, trade journal, and Win Rate % metrics.
- **🌐 Macroeconomic News Dashboard:** High-impact USD economic calendar events, Fear & Greed Index, and central bank gold accumulation drivers.

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/xauusd-gold-terminal.git
   cd xauusd-gold-terminal
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
